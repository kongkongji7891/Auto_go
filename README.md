# Auto_go
一个KataGO驱动的自动对弈软件，通过视觉识别和模拟点击可以自动与他人对弈，支持例如腾讯，野狐等  
**使用方法**:  
安装yl.txt的支持库
如果你以命令行或官方编辑器方式启动，可以直接运行install_lib.py，或者手动在当前目录执行以下CMD命令:
```
pip install ly.txt
```
如果是类似Mind+等第三方编辑器，请将每一行填入安装框  
如果是PyCharm等，请在PS中执行pip install ly.txt  

安装完成之后，可以运行项目根目录的**main.py**启动，请确保已有围棋对弈程序启动
